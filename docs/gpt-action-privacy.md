# Privacy notice — Daily US Stock Screen GPT Action

The Action sends a structured stock-research write request to a GitHub Issue in `Hughey-T/Daily-US-Stock-Screen`. GitHub receives the authenticated account identity, request timestamps, source identifiers, model/prompt metadata, cited public URLs, and research text. The repository Issue is an audit record; do not include personal data, confidential information, credentials, or tokens.

Requests are used only to validate and append auditable prediction records and to return a receipt. GitHub's own privacy and retention terms apply. The ledger deliberately retains request IDs and nonces to prevent replay; prediction records and receipts are append-only public repository artifacts. To ask about removal of accidentally submitted personal data, contact the repository owner, understanding that public Git history may retain prior bytes. The Action does not sell data and exposes no repository-content write API to the GPT.
